📁 SETUP
--------
1. Put this folder next to balance_pinn.py:
   SISCOIN/
   ├── balance_pinn.py
   └── batch_analysys/
       ├── run_all_stages.py  ← You are here
       ├── stage1_test.py
       ├── stage2_subjects.py
       └── stage3_full.py

2. Update DATA_FOLDER path in each stage script:
   DATA_FOLDER = r"G:\human-balance-evaluation-database-1.0.0"

3. Install requirements if not already done:
   pip install numpy torch pandas scipy wfdb scikit-learn matplotlib

================================================================================
🚀 RUNNING THE ANALYSIS
================================================================================

EASIEST WAY (Recommended for first-time users):
------------------------------------------------
cd batch_analysys
python run_all_stages.py

→ This will run all 3 stages with confirmations between each stage.


AUTOMATIC MODE (Run everything without stopping):
--------------------------------------------------
python run_all_stages.py --auto

⚠️  WARNING: This runs all 1,956 files without asking! (~12-24 hours)


INDIVIDUAL STAGES (Manual control):
------------------------------------
python stage1_test.py          # Test: 24 files, ~10 min
python stage2_subjects.py      # Subjects: 163 files, ~2-3 hours
python stage3_full.py          # Full: 1,956 files, ~10-20 hours


OTHER OPTIONS:
--------------
python run_all_stages.py --skip-stage1          # Skip test, start at stage 2
python run_all_stages.py --stage 2              # Start from stage 2
python run_all_stages.py --stages "1,2"         # Only run stages 1 and 2

================================================================================
🔄 RESUME IF INTERRUPTED
================================================================================

If Stage 3 stops (power loss, crash, etc.):
  python stage3_full.py

→ It will ask: "Found existing checkpoint. Resume from it? (y/n)"
→ Type 'y' and press Enter
→ It continues from where it stopped!

Checkpoints saved every 50 files, so you lose at most ~50 files of work.

================================================================================
🆘 TROUBLESHOOTING
================================================================================

ERROR: "File not found"
  → Check DATA_FOLDER path in scripts

ERROR: "Out of memory"
  → Reduce N_TRAIN_POINTS in scripts (try 5000 instead of 8000)

ERROR: "Module not found"
  → Install: pip install numpy torch pandas scipy wfdb scikit-learn matplotlib
  → Make sure balance_pinn.py is in parent directory

TOO SLOW?
  → Check if GPU is being used (should say "cuda" not "cpu")
  → Reduce EPOCHS in scripts (try 3000 instead of 5000)
  → Use only Stage 2 (163 files is often enough for thesis)

SOME FILES FAILED?
  → Check failed_files.csv in output folder
  → Usually due to corrupted data or missing metadata
  → Continue with successful files

================================================================================
📈 USING RESULTS FOR THESIS
================================================================================

QUICK ANALYSIS:
  Use: stage2_subjects_results/subjects_results.csv
  - 163 subjects (one file per subject)
  - Good for correlations, scatter plots, basic stats
  - Fast to process and analyze

COMPLETE ANALYSIS:
  Use: stage3_full_results/subjects_averaged.csv
  - 163 subjects (averaged across all 12 trials)
  - Better statistics (averages reduce noise)
  - More robust parameter estimates

TASK COMPARISON:
  Use: stage3_full_results/tasks_averaged.csv
  - Compare 4 different tasks
  - See how balance parameters change with task
  - ANOVA analysis

VARIABILITY STUDY:
  Use: stage3_full_results/all_1956_files_results.csv
  - All trials (3 repetitions per task)
  - Study within-subject variability
  - Test-retest reliability

================================================================================
📝 COLUMNS IN CSV FILES
================================================================================

subject_number       Subject ID (1 to 163)
weight_kg            Subject weight
height_m             Subject height

stiffness_x          Ankle stiffness X direction (Nm/rad)
stiffness_y          Ankle stiffness Y direction (Nm/rad)
damping_x            Ankle damping X direction (Nm·s/rad)
damping_y            Ankle damping Y direction (Nm·s/rad)

omega_n_x            Natural frequency X (Hz)
omega_n_y            Natural frequency Y (Hz)
zeta_x               Damping ratio X (dimensionless)
zeta_y               Damping ratio Y (dimensionless)

rmse_x               Model error X (meters)
rmse_y               Model error Y (meters)
r2_x                 Model fit quality X (0-1, higher is better)
r2_y                 Model fit quality Y (0-1, higher is better)

task                 Task name (Task1-Task4)
repetition           Repetition number (1-3)
